# Privacy Policy: Mashnu Content Engine

Last updated: 2026-11-25

Mashnu Content Engine is a private tool operated by Mashnu AI (Kiran) to upload the operator's own videos to the operator's own YouTube channel.

- **What it accesses:** only the `youtube.upload` permission, granted by the channel owner, used solely to upload videos the operator generated.
- **What it stores:** an OAuth refresh token held in the operator's own encrypted GitHub Actions secrets. No other user's data is collected, stored, shared or sold.
- **Third parties:** video scripts are generated with Google's Gemini API. No personal data is sent.
- **Revoking access:** the channel owner can revoke access at any time at https://myaccount.google.com/permissions.
